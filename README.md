# Projeto de Vida — Maria, Tomazia e Natasha

Este é um projeto de site responsivo em HTML, CSS e JavaScript desenvolvido para apresentar os projetos de vida profissionais de **Maria (Neuropsicologia)**, **Tomazia (Educação Física)** e **Natasha (Direito)**.

---

## 📁 Estrutura de Arquivos

```text
projeto-de-vida/
├── index.html     # Estrutura principal do site
├── style.css      # Estilização visual e responsividade
├── script.js      # Interatividade e modal informativo
└── README.md      # Instruções do projeto
```

---

## 🚀 Como Executar no VS Code

1. Baixe e extraia o arquivo **`projeto-de-vida.zip`**.
2. Abra o **Visual Studio Code**.
3. Vá em `Arquivo` -> `Abrir Pasta...` e selecione a pasta extraída.
4. (Opcional) Instale a extensão **Live Server** no VS Code.
5. Clique com o botão direito sobre o arquivo `index.html` e selecione **"Open with Live Server"** (ou abra o arquivo `index.html` diretamente em seu navegador).

## 📤 Como Importar para o GitHub

1. Crie uma conta ou faça login no [GitHub](https://github.com).
2. Clique no ícone de `+` no canto superior direito e escolha **New repository**.
3. Escolha um nome para o repositório (ex: `projeto-de-vida`) e clique em **Create repository**.
4. No seu computador, abra o terminal dentro da pasta do projeto e execute os comandos:

```bash
git init
git add .
git commit -m "Primeiro commit - Projeto de Vida"
git branch -M main
git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
git push -u origin main
```
*(Substitua a URL acima pela URL fornecida pelo seu GitHub).*
